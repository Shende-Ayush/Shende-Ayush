### A Few Strong Opinions

1. **If your query takes more than 1 network hop to render a modal, you're doing it wrong.** (PostgreSQL can return a single JSON tree faster than your network can send a second handshake).
2. **If a website scrolls horizontally on an iPhone, it doesn't work.**
3. **Never trust client-side dates without timezone guards.** (`UTCDateTime` or prepare to explain why a booking arrived yesterday).
4. **Debugging memory pointers in C++ at 2 AM builds character.**
5. **Progressive disclosure is king.** Don't show users 18 inputs when 3 will get the job done.
